# Agent Labs

**Reproducible experiments on how AI agents fail, and how to make them reliable and safe.** Each lab states a claim, shows how to reproduce it, and reports limits.

Live (planned): demos under **adityacuz.in** · MIT licensed

> **Status: design phase.** Labs below are scoped; none is built yet.

## Labs
| Lab | You can | Question it answers | Order |
|---|---|---|---|
| **Trace Lab** | Open an agent run as a trace (plan, tool calls, retrieved context, tokens, cost) and see pass/fail per criterion and repeat-run reliability | Did the agent actually do the right thing, and does it do it every time? | 1 |
| **Break My Agent** | Try to prompt-inject a fake-tool agent, unguarded vs behind a deterministic tool-call policy; leaderboard | How much does a policy layer reduce successful injections? | 2 |
| RAG vs Memory | Compare plain RAG with a memory layer on public data, including whether retrieved memory was used | Is fancy memory worth it over a strong RAG baseline? | later |
| Context Window X-ray | See exactly what the model received and what compaction dropped | Where do tokens and cost go? | later |
| Router Dashboard | Watch cost and latency across providers and routing choices | What does cost-aware routing save? | later |

## Rules every lab follows
1. States its **claim**, **inputs** and **known limits** in its README.
2. Numbers are **regenerated by CI**; no figure ships that cannot be reproduced.
3. Cites the original paper or source; secondhand summaries are checked before citation.
4. Safety labs use fake tools and synthetic data only.

## Architecture
Monorepo, one package per lab, a shared trace schema, evals runnable via CLI and CI. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/ROADMAP.md](docs/ROADMAP.md). Traces come from [Agent Workspace](https://github.com/aditya4232/agent-workspace).
