# labs

Research-grounded AI engineering labs with reproducible evals. Status: planning, no code yet.

1. **Trace Lab** - open an agent run as a trace (plan, tool calls, retrieved context, tokens, cost) with pass/fail per criterion and repeat-run reliability.
2. **Break My Agent** - try to prompt-inject a fake-tool agent, unguarded vs behind a deterministic tool-call policy; leaderboard.
Later: RAG vs Memory, Context Window X-ray, Router Dashboard.
Every lab declares: the claim, inputs, how to reproduce, known limits. No number ships that CI cannot regenerate.
