# Agent Labs Roadmap

## Phase 0 — experiment contract
- Shared trace schema, experiment manifest and result schema.
- CLI runner, pinned dependencies and synthetic fixture pack.
- Baseline and evaluation protocol; no public leaderboard.

## Phase 1 — Trace Lab
- Ingest synthetic Agent Workspace traces.
- Timeline viewer, span inspection, assertions and run comparison.
- Redaction and schema validation.

## Phase 2 — Break My Agent
- Synthetic prompt-injection and tool-policy corpus.
- Fake tools and isolated test runner only.
- Attack taxonomy, defense matrix, false-positive review.

## Phase 3 — RAG Reliability and Context Budget
- Matched baselines and held-out datasets.
- Citation quality, retained-fact recall, cost/latency and ablations.

## Phase 4 — Model Router and Tool Reliability experiments
- Pareto analysis across quality, latency and cost.
- Fault injection, retries, approval gates and deterministic policy.

## Publication gate
No result is public without reproducible command, environment/model/dataset versions, sample size, uncertainty, failures, limitations and source commit. Every result can be regenerated by CI or explicitly marked as non-reproducible.
